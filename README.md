# The-Odin-Rock-paper-scissors
A Rock Paper Scissors game built with JavaScript as part of The Odin Project JavaScript curriculum.


A Rock Paper Scissors game built from scratch with JavaScript as part of The Odin Project Foundations curriculum.

## About the Project

This project is focused on practicing JavaScript fundamentals by building the logic for a simple Rock Paper Scissors game played against the computer.

The game is currently played through the browser console, with JavaScript handling the computer's random choice, the player's input, round logic, and score tracking.

## Technologies Used

* HTML5
* JavaScript

## Concepts Practiced

* Variables
* Functions
* Function parameters and arguments
* Return values
* Conditional statements
* User input with `prompt()`
* `Math.random()`
* String methods
* Global and local scope
* Basic game logic
* Score tracking
* Browser developer tools and console debugging
